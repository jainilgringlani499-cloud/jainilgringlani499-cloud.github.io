## 🛠️ Project Alignment & Checklist Mapping

Here is how this website successfully matches every single requirement of the Stardance project guidelines:

### 1. HTML + CSS (Required) & Optional JS
- **HTML:** Built entirely using raw semantic HTML5 layout containers (`<nav>`, `<section>`, `<div>`).
- **CSS:** Styled completely from scratch without external frameworks like Bootstrap.
- **JS (Optional):** Implemented an optional interactive JavaScript script (`engageWarp()`) inside the Silly Lab section to handle micro-scale shifts dynamically.

### 2. Deployed Website (Not Localhost)
- The site is live and fully accessible to anyone on the web using **GitHub Pages** server hosting platforms at the link provided above.

### 3. Core Personal Site Content Sections (5 Total)
The layout exceeds the 3-section minimum requirement by breaking content down logically across five distinct modules:
- 🧑‍🚀 **About Me:** An introduction to who I am as a student developer.
- 💻 **Digital Experiments (Projects):** An aligned display grid showcasing my core web builds.
- 📡 **Telemetry Logs (Blogs):** Writing blocks tracking my personal styling notes.
- 🧪 **Silly Cosmic Lab:** An interactive playground utilizing the JavaScript warp animation engine.
- 📱 **Connect With Me:** Directly configured links pointing straight to my active YouTube channel (`Jainil Gringlani`) and Instagram profile (`@kalpanagringlani`).

### 🎨 4. Custom Creative CSS
- Employs fluid **CSS Glassmorphism** properties using backdrop blurs (`backdrop-filter: blur(12px)`) layered above translucent backgrounds (`rgba`).
- Created a unique **Pure CSS background rendering framework** that maps radial gradients to build smoothly traveling, cascading background star fields without using any external images.
- Features custom project cards that automatically shift configuration formats dynamically on mobile devices.

## 🤖 AI Usage Disclosure Statement
*Requirement: "No website should be made with heavy AI usage, and let us know how you used AI."*

**How I Used AI on This Project:**
I utilized AI as an interactive learning assistant to build this project efficiently. I personally configured the semantic HTML structure, text blocks, local profile image paths, and social handle routes. However, I encountered multiple alignment collapses and CSS keyframe syntax errors when trying to nest the twinkling star engine directly inside my `.stars` container block. I used the AI to help me debug those nesting constraints by pulling the `@keyframes` block outside properly according to vanilla CSS compilation standards.
